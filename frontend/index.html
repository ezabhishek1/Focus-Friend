OPEN SOURCE ARCHITECTURE

Focus Friend // Hacktoberfest PRD

🎯 Target Friend: Alex

Alex experiences severe Task Paralysis from 50+ Slack messages and rambling emails daily. The cognitive friction of separating emotional fluff from real deliverables leads to avoided notifications and forgotten tasks.

⚡ The Three Pillars

  • The Vibe: Eliminates rejection sensitivity by spelling out the emotional context plainly.
  • The Deadline: Extracts the actual target date so calendars aren't missed.
  • The Action Item: One single imperative bullet point that tells the brain exactly what to do first.

🔒 Local-First Open Source Stack

  • Model: Phi-3-mini-4k-instruct (Microsoft Open Weights, 2.3GB).
  • Engine: Ollama running locally at localhost:11434.
  • Zero Telemetry: 0% of emails or chat logs ever leave the local machine. Works completely offline.
  • Design System: Aesthetic Neo-Brutalism for maximum high-contrast clarity and zero distracting clutter.
